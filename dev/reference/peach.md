# uni.kn color Peach

`Peach` provides the preferred color of
[`pal_peach`](https://hneth.github.io/unikn/dev/reference/pal_peach.md)
(as an atomic HEX character value) and is defined as
[`pal_peach`](https://hneth.github.io/unikn/dev/reference/pal_peach.md)`[[4]]`.

## Usage

``` r
Peach
```

## Details

See
<https://www.uni-konstanz.de/en/university/news-and-media/create-online-and-print-media/corporate-design/>
for details.

## Examples

``` r
Peach  # HEX character "#FEA090" (as value)
#>     Peach 
#> "#FEA090" 
all.equal(Peach, pal_peach[[4]])  # TRUE (same HEX values)
#> [1] "names for target but not for current"

seecol(Peach)  # view color and details

```
