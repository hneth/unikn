## Color manipulation functions

Commands for viewing, creating, changing, finding and using colors and
color palettes.

- [`seecol()`](https://hneth.github.io/unikn/reference/seecol.md) : Plot
  color palettes (to see their colors)
- [`usecol()`](https://hneth.github.io/unikn/reference/usecol.md) : Use
  a color or color palette
- [`simcol()`](https://hneth.github.io/unikn/reference/simcol.md) : Find
  similar colors
- [`grepal()`](https://hneth.github.io/unikn/reference/grepal.md) : Get
  a vector of colors whose names match a regular expression
- [`newpal()`](https://hneth.github.io/unikn/reference/newpal.md) :
  Define a new color palette
- [`demopal()`](https://hneth.github.io/unikn/reference/demopal.md) :
  Demonstrate a color palette (in a plot)
- [`plot_cube()`](https://hneth.github.io/unikn/reference/plot_cube.md)
  : Plot colors as points in a 3D RGB color cube
- [`shades_of()`](https://hneth.github.io/unikn/reference/shades_of.md)
  : Get n shades of a color
- [`ac()`](https://hneth.github.io/unikn/reference/ac.md) : Adjust color
  transparency
- [`get_col_names()`](https://hneth.github.io/unikn/reference/get_col_names.md)
  : Get color names

## Plotting functions

Functions for plotting objects and themes.

- [`slide()`](https://hneth.github.io/unikn/reference/slide.md) : Plot a
  slide (or frame)
- [`xbox()`](https://hneth.github.io/unikn/reference/xbox.md) : Plot a
  box (with x)
- [`theme_bwkn()`](https://hneth.github.io/unikn/reference/theme_bwkn.md)
  : An alternative bw theme (for ggplot2)
- [`theme_grau()`](https://hneth.github.io/unikn/reference/theme_grau.md)
  : An alternative grey theme (for ggplot2)
- [`theme_minikn()`](https://hneth.github.io/unikn/reference/theme_minikn.md)
  : An alternative minimal theme (for ggplot2)
- [`theme_unikn()`](https://hneth.github.io/unikn/reference/theme_unikn.md)
  : Basic unikn theme (for ggplot2)

## Text decoration functions

Functions for decorating plotted text.

- [`heading()`](https://hneth.github.io/unikn/reference/heading.md) :
  Plot a heading (as marked text elements)

- [`mark()`](https://hneth.github.io/unikn/reference/mark.md) : Plot
  marked (or highlighted) text elements

- [`post()`](https://hneth.github.io/unikn/reference/post.md) : Post
  text (in an xbox)

- [`uline()`](https://hneth.github.io/unikn/reference/uline.md) : Plot
  underlined text elements

- [`url_unikn()`](https://hneth.github.io/unikn/reference/url_unikn.md)
  :

  `url_unikn` formats an URL the uni.kn way
